Release of Edirom Online v2.5.0

2026-09-30

The new version 2.5.0 of Edirom Online includes the latest backend and frontend versions which have also just been released as Edirom Online Backend v1.5.0 and Edirom Online Frontend v1.5.0.

The Concordance Navigator is now implemented as a Web Component. The backend now supports measures that stand for several measure numbers and the DTS document endpoint has been extended. In addition, unused features have been removed and the documentation has been extended. Please visit the respective releases for more information.
